### 📈 Impact & Architectural Wins

- 📉 **Infrastructure Cost Optimization:** Led a company-wide server rightsizing initiative across warehouse workloads, effectively cutting overall infrastructure spend by **~30%**.
- ⚡ **Analytics & Reporting Overhaul:** Redesigned dashboards and archival lookups utilizing **Amazon Redshift**, transforming typical query latencies from **minutes down to seconds**.
- 🔄 **Decoupled Data Pipelines:** Architected near real-time ingestion pipelines, successfully isolating heavy analytics workloads from core transactional systems to ensure maximum uptime.
- 🔐 **Unified Identity & RBAC:** Spearheaded the migration from fragmented per-service auth logic to a unified **Keycloak** identity layer across all tenants, significantly reducing auth-related incidents.
- 🏗️ **Platform Abstractions:** Designed configurable sequence-generation services and reusable scheduler orchestration templates, retiring massive amounts of duplicate code across dozens of microservices.
